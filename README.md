# delNiko
delNiko is a full-vibecode project.

# password gen
generates random passwords with adjustable length and symbols, copies them to clipboard in one click.

# auto clicker
clicks the left mouse button at a fixed speed of 5 cps. press `f6` at any time to stop it.

# shutdown timer
sets a timer in minutes to automatically turn off your pc, or cancels an active timer.

# qr generator
creates a qr code from any link or text, shows a preview, and lets you save it as a png file.

# temp cleaner
deletes junk files from the windows temporary (`temp`) folder to free up disk space.

# quick notes
simple built-in notepad that saves your text into a `delniko_notes.txt` to appdata.

# net ping
checks your internet connection speed and packet loss to `8.8.8.8` or any custom website/ip.

# img converter
converts images between `jpeg`, `png`, and `webp` formats offline.

# file sorter
organizes messy folders (like downloads) by sorting files into `images`, `archives`, `programs`, and `docs` subfolders.

# unit calc
converts megabytes (`mb`) into gigabytes (`gb`) and terabytes (`tb`) as you type.
